Delivery with Distance-Based Pricing
====================================

[Русская версия](README.md)

A shipping plugin that allows you to calculate delivery cost based on distance in kilometers specified by the customer.

The plugin prompts the customer to enter the distance in kilometers and calculates the shipping cost based on this value. No external services are used for distance determination — the value is entered manually. The store manager can verify and adjust the amount when confirming the order.

## Features

- Restrict plugin functionality to specific countries and regions
- Calculate shipping taking into account minimum and maximum order weight
- Calculate shipping taking into account minimum and maximum order cost
- Built-in localization support: Russian, English, Belarusian, Kazakh, and Ukrainian

## Important Note

The plugin has limited functionality in step-by-step checkout mode — shipping cost calculation occurs only when proceeding to the next step.
